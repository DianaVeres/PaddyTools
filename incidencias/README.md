# Paddy Tools · Incidencias — versión fiel al programa original

Esta versión usa la interfaz HTML extraída del ejecutable original `PaddyIncidenciasCompartido13.exe`.
No modifica el programa original del PC.

La aplicación conserva:
- búsqueda de pedidos en WooCommerce,
- registro de incidencias,
- colegio de la incidencia y reincidencias,
- recogidas por colegio,
- mediciones,
- incidencias de tienda y fotografía del ticket,
- impresión de incidencia y etiqueta,
- sincronización con el registro compartido de Google,
- integración segura con Gestión Unificada mediante handoff.

Los secretos de WooCommerce y del registro compartido se configuran solo como variables de Railway.
