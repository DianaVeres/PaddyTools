# Manuales visuales de PaddyTools

Esta carpeta contiene los dos documentos vigentes para formación y envío:

- `Guia_rapida_visual_PaddyTools`: explicación breve y muy visual.
- `Manual_completo_PaddyTools`: explicación detallada de todos los módulos.

Los archivos editables están en formato Word y sus versiones listas para
compartir están en PDF. Las capturas anonimizadas utilizadas como fuente se
guardan en `assets/`.

Los documentos se generan con `scripts/build-paddytools-manuals.py`; el PDF se
exporta con `scripts/export-manuals-pdf.ps1`. Los renders `_qa_*` son temporales
de comprobación visual y no forman parte del repositorio.
